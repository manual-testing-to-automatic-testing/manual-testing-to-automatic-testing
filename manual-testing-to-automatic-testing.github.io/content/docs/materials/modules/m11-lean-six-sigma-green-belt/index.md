# M11 Lean Six Sigma Green Belt, lifetime certification

Hours 180–220, 40 hours, the same for every track. Assessed by the certification body's exam and a project review. Completes the programme with Gate 4.

## Purpose

Manual testing is itself the variation problem that Six Sigma targets: the same check, run by hand, does not give the same result every time. Automation removes that variation, but only measurement shows that it did. M11 gives every participant the Lean Six Sigma Green Belt method to measure a testing process, find root causes, and prove an improvement, and a Green Belt certification that does not expire.

M11 comes last because a Green Belt project needs what the earlier modules produce: automation skills, the E1 automation candidate analysis, and the E9 suite-health data.

## Outcomes

- **LO14:** apply Lean Six Sigma (DMAIC) to measure and improve a testing process, and hold a Green Belt certification that does not expire.

## Green Belt projects by track

Every project improves a real measure in the person's own team's testing process, uses synthetic data only, and builds on their E1 analysis and E9 suite-health report. Typical measures:

- flaky test rate
- time from a defect report to a regression test
- manual regression hours per release
- defects found after release
- CI run time

| Track | Project |
| --- | --- |
| B3, B4-QA, B4-TE | A named part of a team project, led by the mentor or a B6 or B7 colleague. The part is written in the charter. |
| B5-QA, B6-TE | A small project of their own. |
| B6-QA, B7-TE | Lead a project, and coach a lower-band colleague's part. |
| B7-TM | Lead a project for their area, and sponsor the cohort's other projects with the product owners. |

## Activities

1. Map the team's test process as a value stream, and mark the waste.
2. Write and agree the [Green Belt project charter](project-charter.md).
3. Collect baseline data, and work out the process's current capability.
4. Find the root causes with a Pareto chart and a fishbone diagram, and test one with data.
5. Pilot an improvement, measure the result, and write a control plan for the process owner.
6. Prepare for, and sit, the certification exam.

## Assessment

- The certification body sets and marks the Green Belt exam. If a person does not pass, they resit once, within three months, after more exam preparation.
- The training lead and mentor review the project, with the product owner as sponsor. The project is accepted when its measure, data, analysis, and control plan are sound, whether or not the improvement was as large as hoped.
- A person completes the programme when Gate 4 is met and E11 is complete (spec, "Completion").
