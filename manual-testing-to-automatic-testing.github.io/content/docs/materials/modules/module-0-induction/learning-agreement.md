## What we agree

1. **The person stays in their current band and UK GDaD PCF role.** This programme does not change band, role, or pay.
2. **Gates are developmental.** A gate result never starts a capability, performance, or conduct procedure by itself.
3. **Protected time:** 220 learning hours (280 for the Band 3 and Band 4 extension), including 40 hours for the Lean Six Sigma Green Belt, by default 7.5 hours a week. Agreed pace: ______ hours a week, on these days: ______. It is in the person's calendar. It is not reassigned to delivery work without the training lead's agreement.
4. **Mentor time:** 1.5 hours per 7.5 learning hours for hours 0–45, then 1 hour per 7.5 learning hours (about 27 hours in all).
5. **Gate dates:**

   | Gate | Date |
   | --- | --- |
   | Gate 0 | |
   | Gate 1 (hour 45) | |
   | Gate 2 (hour 90) | |
   | Gate 3 (hour 127.5) | |
   | Gate 4 (hour 180) | |
   | Gate 5 (follow-up, about six months after Gate 4) | |

6. **Self-assessment:** the person completes the full capability self-assessment honestly, with evidence, at every gate. The line manager rates independently. Both meet to calibrate.
7. **Safety and governance:** the person uses synthetic data only, never real patient data, and never puts secrets in source control.
8. **AI assistants:** the person may use them, and must be able to explain every line they submit.
9. **Reasonable adjustments:** as recorded in the individual learning plan, and reviewed at every gate.
10. **Escalation:** if more than 7.5 hours of protected time are lost and not rescheduled within the same gate period, the training lead raises it with the line manager.
