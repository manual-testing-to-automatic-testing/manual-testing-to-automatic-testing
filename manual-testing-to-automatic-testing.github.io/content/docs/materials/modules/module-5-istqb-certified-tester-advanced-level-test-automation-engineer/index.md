# Module 5 ISTQB Certified Tester Advanced Level Test Automation Engineer

The ISTQB Certified Tester Advanced Level Test Automation Engineer (CTAL-TAE): about 24 hours, the same for every track, after the Foundation Level. Recorded at Gate 0.

## Purpose

The CTAL-TAE certification covers how to design, build, and run test automation that lasts: test automation architecture, design, deployment, reporting, and continuous improvement. It gives every participant a recognised, vendor-neutral framework for the automation they build in the rest of the programme.

## Outcomes

- Explain test automation architecture, design, and deployment as the CTAL-TAE syllabus describes them.
- Hold the ISTQB Certified Tester Advanced Level Test Automation Engineer certificate.

## Prerequisite

The ISTQB Certified Tester Foundation Level certificate, from [Module 4](../module-4-istqb-certified-tester-foundation-level/index.md).

Each person's sessions add up to 24 hours. The course days are protected time: the line manager clears them in the person's calendar.

## Activities

1. With the training lead, book a course date and the exam, using the course's exam voucher.
2. Before the course, read the syllabus's introduction and learning objectives.
3. Take the 3-day course.
4. Use the provider's learning platform for revision and sample exams.
5. Sit the certification exam.

## Evidence

**Evidence 5:** the ISTQB Certified Tester Advanced Level Test Automation Engineer certificate.

## Assessment

The exam provider sets and marks the exam. Gate 0 (hour 88) records the certificate. If a person does not pass, they agree more revision with their mentor, and resit within three months.
