# 4 Implementing Test Automation

Part of the [CTAL-TAE syllabus, explained](index.md).

**Time in the syllabus:** 150 minutes. **Highest level:** K4. **Keywords to remember:** risk, test fixture.

## In plain words

How to run a test automation pilot, the deployment and technical risks to plan for, and what keeps a test automation solution maintainable.
