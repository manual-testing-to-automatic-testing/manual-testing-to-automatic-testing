# ISTQB CTAL-TAE syllabus, explained

The concepts of the [ISTQB Certified Tester Advanced Level Test Automation Engineering (CTAL-TAE) syllabus, version 2.0](https://www.gasq.org/files/content/ISTQB2/ISTQB_CTAL-TAE_Syllabus_v2.0.pdf), explained in plain words, with examples from this programme, and ready to teach. It supports [Module 5 ISTQB Certified Tester Advanced Level Test Automation Engineer](../index.md).

## How to use these pages

Each learning objective has a page with: **In short**, the idea in one or two sentences; **Key ideas**; **In this programme**, an example from our JavaScript, Selenium, Mocha, and FHIR practice; **Teach it**, a session a mentor or trainer can run; and **Check yourself**, questions to answer without notes. Read them before the course, or use them to revise for the exam.

## About the syllabus and the exam

- The syllabus is for anyone who builds or improves test automation: testers, test analysts, test automation engineers, developers, and their managers. It expects some software engineering skill, but does not teach it.
- **Entry requirement:** the ISTQB Certified Tester Foundation Level certificate ([Module 4](../../module-4-istqb-certified-tester-foundation-level/index.md)). ISTQB also recommends at least six months' experience in testing or development, and an accredited course.
- **Levels of knowledge:** K2 understand, K3 apply, and K4 analyse. Each learning objective has a level. The keywords under each chapter heading must be remembered.
- **What is examinable:** chapters 1 to 8. The introduction and the appendices are not. Answers can draw on more than one section.
- **Business outcomes:** the certificate shows that a person can describe the purpose of test automation; place it in the lifecycle; set up the infrastructure; choose tools and strategies; design modular, scalable solutions; plan a pilot and deployment; design and develop solutions; plan maintenance; integrate with CI/CD; collect, analyse, and report data; verify the infrastructure; and improve continuously.
