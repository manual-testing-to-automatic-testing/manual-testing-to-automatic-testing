# 1.1 Purpose of Test Automation

Part of [1 Introduction and Objectives for Test Automation](1-introduction-and-objectives-for-test-automation.md).

## In plain words

Test automation means using tools to set up, run, and check tests. This section weighs what it gives you against what it costs, and names what it can never do.
