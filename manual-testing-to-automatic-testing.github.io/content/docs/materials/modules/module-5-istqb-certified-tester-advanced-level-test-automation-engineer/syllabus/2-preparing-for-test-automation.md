# 2 Preparing for Test Automation

Part of the [CTAL-TAE syllabus, explained](index.md).

**Time in the syllabus:** 180 minutes. **Highest level:** K4. **Keywords to remember:** API testing, GUI testing, testability.

## In plain words

Before automating, make sure the system can be tested (testability), understand the environments tests will run in, analyse the system to decide what the automation solution needs, and compare tools against those needs.
