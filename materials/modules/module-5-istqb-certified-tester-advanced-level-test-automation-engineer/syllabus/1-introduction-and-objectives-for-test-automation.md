# 1 Introduction and Objectives for Test Automation

Part of the [CTAL-TAE syllabus, explained](index.md).

**Time in the syllabus:** 45 minutes. **Highest level:** K2. **Keywords to remember:** system under test, test automation, test automation engineer.

## In plain words

Why automate tests at all, what it costs, what it cannot do, how it fits each way of building software, and how to choose tools for the system you are testing.
