# 8 Continuous Improvement

Part of the [CTAL-TAE syllabus, explained](index.md).

**Time in the syllabus:** 210 minutes. **Highest level:** K4. **Keywords to remember:** schema validation, test histogram.

## In plain words

How to keep improving test automation: using data to improve tests, improving each part of a deployed solution, restructuring it as the system changes, and using automation for more than testing.
