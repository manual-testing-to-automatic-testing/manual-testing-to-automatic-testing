# 7 Verifying the Test Automation Solution

Part of the [CTAL-TAE syllabus, explained](index.md).

**Time in the syllabus:** 135 minutes. **Highest level:** K3. **Keywords to remember:** static analysis.

## In plain words

The test automation is software too, so it must be checked: its environment and tools, its suites, its unexpected results, and the quality of its code.
