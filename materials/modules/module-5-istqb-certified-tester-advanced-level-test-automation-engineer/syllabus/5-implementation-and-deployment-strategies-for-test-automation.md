# 5 Implementation and Deployment Strategies for Test Automation

Part of the [CTAL-TAE syllabus, explained](index.md).

**Time in the syllabus:** 90 minutes. **Highest level:** K3. **Keywords to remember:** contract testing.

## In plain words

How automated tests run in CI/CD pipelines at each test level, how testware is configuration-managed across environments and releases, and what API test automation depends on.
