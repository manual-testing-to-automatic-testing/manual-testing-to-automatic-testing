# M2 Programming foundations in TypeScript

Weeks 2–6. Reviewed at Gate 1.

## Purpose

A browser automation tool is a library you call from a programming language. M2 gives each person enough TypeScript to write, run, debug, and test small programs. It also meets the base of the testing pyramid early: every kata has unit tests the person wrote.

## Outcomes

- **LO2:** write, run, debug, and refactor TypeScript code to the team's standards.

## Activities

1. Variables, types, functions, control flow, arrays and objects, modules, and errors.
2. `async` and `await`.
3. The terminal, npm, the VS Code debugger, autocomplete, and syntax highlighting.
4. A first unit test, then a unit test for every kata.
5. The kata set for your track. See [kata-guide.md](kata-guide.md).

## Assessment

Gate 1 (week 6) reviews E2 with E1 and E3. The Gate 1 Part D practical is "fix a failing unit test and open a pull request", so M2 and M3 together prepare for it.
